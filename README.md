# KleeneStar.Help
Provides a centralized help workspace with documentation, guides, tutorials, and support resources for KleeneStar applications and services.

The plugin seeds the workspace **KleeneStar Help** (`HELP`): a home page, the chapters *First Steps*, *Guides* and *Frequently asked questions*, and the help pages below them. Every page follows one template (instruction text with version, lead with illustration, horizontal rule, table of contents, one heading 1 per topic) and is illustrated in the colours and with the mark of KleeneStar. All texts are shipped in English and German and written in the language of the installation (`WebExpress:Culture`). The topics carry the landing labels `First Steps`, `Help` and `FAQ`, so they appear on the start page and in the header's help menu.

- Concept and rules: [docs/kleenestar.help.md](docs/kleenestar.help.md)
- Illustrations: `src/KleeneStar.Help/Assets/img`, generated by `node tools/illustrations.mjs`
- Tests: `src/KleeneStar.Help.Test` (run the xUnit v3 binary `KleeneStar.Help.Test.exe`)
